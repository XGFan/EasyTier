# 术语表(本 fork)

只收录本 fork 自己引入、或在 fork 语境下有特定含义的词。上游 EasyTier 的通用概念
(peer、relay、exit node、proxy network 等)以上游文档为准。

## 全隧道(full tunnel)

节点把 `0.0.0.0/0` 交给一个出口节点转发的运行模式。本 fork 存在的唯一理由是让它在
macOS 上能用。相对概念是**子网代理**:只把出口节点暴露的某些网段交给隧道。

## underlay

承载隧道本身的物理网络路径:节点的物理网卡、它的默认网关、它对外呈现的公网 IP。
全隧道的核心矛盾就是 underlay 流量必须绕开自己下发的默认路由,否则形成环路。
"underlay socket"指 easytier 用来和 peer 通信、做 STUN 探测、打洞的那些 socket,
它们必须在 underlay 上而不能在 TUN 上。哪些 socket 算 underlay,由 socket 的 purpose 决定
(见 `easytier/src/arch/macos/underlay.rs`)。

## 拆分路由(split route)

用 1/8、2/7、4/6、8/5、16/4、32/3、64/2、128/1 八条网关型路由代替一条 0.0.0.0/0
或两条 /1。目的不是覆盖面(那和 /1 一样),而是避开 macOS 内核给"目标为 0.0.0.0 的路由"
打上的 `RTF_GLOBAL` 标记,该标记会让 scoped socket 的 sendto 失败。

## bypass 路由

为某个活跃 peer 的 underlay 端点下发的 /32 路由,指向物理网关,确保到它的流量不进 TUN。
由本 fork 下发也由本 fork 回收;不属于本 fork 的 /32 一律不动。

## 静默失效

跟上游之后补丁依然编译、单测依然全绿,但全隧道下打洞悄悄失败退化为中继,只表现为
"网慢了点"。它是 follow 上游时真正的风险,SOP 的整套设计都是为了让它"响"。

## 不变量守卫

专门用来抓静默失效的单测:断言上游没有绕过 socket 工厂新建 socket、工厂仍在咨询绑定决策、
wildcard bind 仍会打上 `IP_BOUND_IF`;上游新增 socket purpose 则直接编译失败。守卫失败不代表
功能一定坏了,但代表必须有人去看。

## gate

实机验证,follow 上游流程里唯一不能自动化跳过的一步;任何一项 FAIL 都阻断发布。
它检查的是路由表实际形态、socket 实际走向、真实出口 IP、p2p 而非 relay,单测盖不到。

## 测试机(mini)

跑 gate 的专用机器。定义性特征是**它到出口节点暴露子网的唯一路径是隧道**;开发机因为和
出口节点同在一个 LAN 而不满足这一条,所以永远不能当测试机。当前是一台 Mac mini,
通过 CPE 独立上网,与开发机以对连网线相连。

## 对连网线(cable link)

开发机与测试机之间的直连以太网,静态地址、无网关。只承载 SSH 和文件传输,不参与
隧道,也不能通向出口节点的子网,否则测试机就不再满足"唯一路径是隧道"。

## 出口 IP 判定

gate 里对"流量确实从出口节点出去"的两条检查。**国内判定**:测试机经隧道看到的公网 IP
必须等于开发机当次看到的家宽 IP(同一出口,动态,每次现测)。**国外判定**:境外回显必须能通
且不等于测试机自己的 underlay IP;具体是哪个 IP 不判定,因为出口侧会把境外流量代理走。
